# 📊 Sales Dashboard (Day 7)

## 📌 Project Overview

This project is developed using **Python**, **NumPy**, **Pandas**, and **Matplotlib** to analyze sales data from a CSV file and visualize the results using different charts.

The dashboard provides insights into monthly sales performance through statistical analysis and graphical representation.

---

## 🎯 Objectives

- Read sales data from a CSV file.
- Analyze sales using NumPy.
- Calculate total, average, maximum, and minimum sales.
- Visualize sales data using Bar, Line, and Pie charts.

---

## 🛠 Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook (Anaconda)

---

## 📂 Files Used

- `sales.csv` – Monthly sales dataset
- `sales_dashboard.ipynb` – Python Notebook

---

## ✨ Features

- Read CSV data using `read_csv()`
- Convert data into NumPy arrays
- Calculate:
  - Total Sales
  - Average Sales
  - Maximum Sales
  - Minimum Sales
- Display:
  - 📊 Bar Chart
  - 📈 Line Chart
  - 🥧 Pie Chart

---

## ▶️ How to Run

1. Open Anaconda Jupyter Notebook.
2. Place `sales.csv` in the same folder as the notebook.
3. Open `sales_dashboard.ipynb`.
4. Run all cells.
5. View the sales statistics and charts.

---

## 📈 Output

The project displays:

- Monthly Sales Data
- Total Sales
- Average Sales
- Maximum Sales
- Minimum Sales
- Bar Chart
- Line Chart
- Pie Chart
